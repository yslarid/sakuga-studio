# Afterlight

**Afterlight.mp4** is a four-second, silent motion study. An amber sun passes over layered ridgelines in three shots. **Pulse-120.wav** is a matching synthesized percussion track at 120 BPM. Both files were generated for this repository from geometric shapes and synthesized audio.

Click **Open example** in the editor to load the pair. You can also import them together with **Choose files**.
